# 🎁 내 기프티콘함

폰에만 저장되는 기프티콘 보관함입니다. 기프티콘 사진을 올리면 **사진 속 유효기간을 브라우저에서 직접 읽어(OCR)**
채워 주고, **유효기간이 임박한 순서대로 자동 정리**해 줍니다. 서버도 로그인도 없고, 사진과 정보는 이 브라우저
안(IndexedDB)에만 남습니다.

## 이렇게 씁니다

1. **＋ 기프티콘 추가** → 기프티콘 사진 고르기 (여러 장 한 번에 가능)
2. 사진마다 `유효기간 읽는 중…` 표시가 뜨고, 읽어낸 날짜가 달력 칸에 자동으로 들어갑니다.
   - 잘못 읽혔거나 못 읽었으면 달력에서 바로 고치면 됩니다.
   - 상품명·메모는 비워 두어도 저장됩니다.
3. **보관함에 담기** → 카드가 유효기간 순으로 정렬됩니다.
   - 7일 이내: 주황색 `D-3` · 오늘 만료: 빨간 `D-Day` · 지난 것: 진한 `만료` 뱃지와 함께 맨 위 `만료됨` 그룹
4. **카드를 누르면** 사진이 전체 화면으로 크게 열립니다(매장에서 바코드 찍기 좋게).
   아래 **사용완료 (삭제)** 를 누르면 지워지고, 6초 동안 **되돌리기**가 뜹니다.
   카드 오른쪽 위의 작은 `사용완료`로 바로 지울 수도 있습니다.
5. 카드/모달의 연필 아이콘으로 상품명과 유효기간을 나중에 고칠 수 있습니다.

## 백업 (폰을 바꿀 때)

오른쪽 위 **⋯ → 백업 파일로 내보내기** 를 누르면 사진과 유효기간이 담긴 JSON 파일 하나가 저장됩니다.
새 폰에서 앱을 열고 **백업 파일 가져오기** 로 그 파일을 고르면 그대로 복원됩니다(기존 목록에 더해집니다).

> 사진과 정보는 서버로 보내지 않고 이 브라우저에만 저장됩니다. 그래서 브라우저 기록/사이트 데이터를 지우면
> 함께 지워집니다. 폰을 바꾸기 전에는 꼭 백업해 두세요.

## 홈 화면에 추가

- **안드로이드 크롬**: 주소창 오른쪽 ⋮ → `홈 화면에 추가`(또는 `앱 설치`)
- **아이폰 사파리**: 공유 → `홈 화면에 추가`

앱 이름은 **내 기프티콘함** 으로 표시됩니다. 한 번 열어 두면 오프라인에서도 보관함이 열립니다(사진 자동 읽기는
처음 한 번 인터넷이 필요합니다).

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조(목록·추가 시트·확대 모달·메뉴) |
| `styles.css` | 카카오톡 선물함 느낌의 모바일 우선 디자인 |
| `app.js` | IndexedDB 저장, 정렬, 모달, 삭제/되돌리기, 백업/복원, OCR 진행 표시 |
| `ocr-date.js` | OCR로 읽은 글자에서 유효기간 날짜를 골라내는 파서 |

## 동작 방식 메모

- **저장**: 브라우저 `IndexedDB`(`gifticon-box` → `gifticons`)에 사진 Blob과 정보를 함께 저장합니다.
  사진은 긴 변 2000px·JPEG(품질 0.92)로 줄여 보관해 용량을 아끼고, 바코드는 그대로 읽을 수 있습니다.
- **자동 정렬**: 만료된 것(최근 만료 순) → 사용 가능한 것(유효기간 짧은 순). 저장·삭제·수정 때마다 다시 계산하고,
  1분마다 날짜를 다시 확인해 자정이 지나면 뱃지가 바뀝니다.
- **OCR**: [Tesseract.js](https://github.com/naptha/tesseract.js) 5.x(CDN)를 브라우저에서 돌립니다.
  한국어 모델(`kor`)로 읽고, 첫 실행 때만 모델을 내려받아 캐시합니다(그 뒤로는 빠릅니다).
  사진은 긴 변 1600px로 줄여 인식 속도를 높입니다.
- **날짜 고르기 규칙**(`ocr-date.js`): 아래 표기를 모두 인식합니다.
  `2026.12.31` `2026-12-31` `2026/12/31` `2026년 12월 31일` `2026. 12. 31` `~26.12.31` `26.12.31까지`
  `유효기간 : 2026.12.31` `교환기간 2026.12.01 ~ 2026.12.31`(→ 끝 날짜) `2026 12 31` `２0２６.１２.３１`
  - Tesseract가 한국어를 `유 효 기 간` 처럼 띄어 읽는 점을 감안해, 글자 사이 공백을 허용해 표지를 찾습니다.
  - 날짜가 여러 개면 **유효기간/사용기간/교환기간/기한/까지** 표지 바로 뒤 날짜 → 기간(`~`)의 끝 날짜 → 미래 날짜 순으로 고릅니다.
  - 바코드 숫자나 `23,000원` 같은 값은 날짜로 오인하지 않습니다.
  - 못 읽으면 화면에 `날짜를 못 찾았어요` 라고 알려 주고, 달력에서 직접 고르면 됩니다.
